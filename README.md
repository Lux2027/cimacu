# Cimacu

3D-Abenteuerspiel für Smartphone und Tablet, läuft direkt im Browser.

**Spielen:** https://lux2027.github.io/cimacu/

- Linke Bildschirmhälfte: Daumen ziehen = laufen
- Rechte Bildschirmhälfte: wischen = Kamera drehen
- Am PC: W A S D oder Pfeiltasten

Gebaut mit [Babylon.js](https://www.babylonjs.com/).
